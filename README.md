# My Portfolio Website

A clean and minimal personal portfolio website built as a beginner project.

## Tech Stack
- HTML
- CSS
- Vanilla JavaScript
- GitHub Pages (for deployment)

## Pages
- **Home** - Welcome page with introduction
- **About Me** - Bio, education, and skills
- **Projects** - Showcase of projects

## Fonts
- **Headings**: Erode (serif)
- **Body Text**: Recia (serif)
- Source: [Fontshare](https://fontshare.com)

## How to Use
1. Clone this repository
2. Open `index.html` in your browser
3. Customize content with your own information

## Deployment
This project is ready for GitHub Pages deployment.
